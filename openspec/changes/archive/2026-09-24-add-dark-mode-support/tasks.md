## 1. Host theme detection utility
- [x] 1.1 Create `src/utils/hostTheme.ts` exporting `watchHostTheme()`, which subscribes to the SDK's `window` `"themeApplied"` event and toggles `document.documentElement.classList` for `dark` based on the luminance of the applied background color variable.
  - Also does an immediate synchronous check against the CSS variable the SDK already wrote to `:root`, rather than relying solely on the event: `SDK.applyTheme()` dispatches `"themeApplied"` synchronously inside `SDK.init()`'s handshake callback, before `init()`'s promise resolves — so a listener attached after `await SDK.ready()` would otherwise miss the initial dispatch and only pick up later `"themeChanged"`-driven re-applies.
- [x] 1.2 Call `watchHostTheme()` from `src/TimeSheetTab.tsx` after `await SDK.ready()`.
- [x] 1.3 Call `watchHostTheme()` from `src/project-timesheet.tsx` after `await SDK.ready()`.
